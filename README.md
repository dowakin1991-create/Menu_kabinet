# KABINET — графік команди

Статичний застосунок: index.html для працівників, admin.html для адміністратора.
Проєкт Firebase: kabinet-graphik-v2. Збірка не потрібна.

## Запуск
1. Firebase Authentication: увімкнути Email/Password та Anonymous.
2. Firestore: опублікувати вміст firestore.rules.
3. GitHub Pages: гілка main, каталог / (root).
4. Адмінка: увійти створеним обліковим записом адміністратора.

## Доступ
Зміни, працівників і бенкети редагує лише UID адміністратора з js/config.js і firestore.rules.
Працівник відкриває головну сторінку, копіює свій код доступу та передає адміністратору.
Адміністратор натискає ім’я працівника й зберігає цей код у полі доступу.
Правила дозволяють працівнику записувати побажання лише для прив’язаного профілю.
Після очищення даних браузера код треба прив’язати заново.
Графік доступний для перегляду всім, хто відкрив посилання і отримав гостьову сесію;
це не закритий портал для конфіденційних даних.

## Чеки і повідомлення
Чеки додаються HTTPS-посиланнями (до 8), Firebase Storage не використовується.
Повідомлення передаються через системне меню «Поділитися»; токенів Telegram немає.
Перший графік порожній: адміністратор додає працівників і призначає зміни.
