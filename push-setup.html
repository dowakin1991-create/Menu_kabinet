Ключ сповіщень

Одноразове налаштування власником. Ключ створюється на цьому пристрої та нікуди не надсилається.

Якщо VAPID_JSON уже налаштовано, не замінюй його: старі підписки можуть перестати працювати.

Скопіюй весь текст у Cloudflare: Runtime variables and secrets → Add variable. Назва: VAPID_JSON, позначка Secret, середовище Production.

Натисни Add variable and deploy у Cloudflare. Не надсилай цей текст у чат. До збереження не оновлюй цю сторінку: ключ не зберігається в браузері.
